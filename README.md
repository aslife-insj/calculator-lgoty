- pamyatka.pdf: исходная памятка со ставками (устарели).
- Опубликованная версия: https://claude.ai/artifact/X5et17q3zh5cfYEnTTYsZb (версия 2)
- Дизайн-система: «Кабинет ИСЖ», https://claude.ai/artifact/7jVK8SR6mtqe4TARYkfrKr

Параметры по умолчанию (из памятки, надо актуализировать): ГСС Fort Knox 160%, Unit Linked 16% годовых, НДФЛ 15%, лимит дохода 30 млн ₽.

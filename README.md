# Калькулятор налоговой льготы (НСЖ и Юнит Линк)

Одностраничный сайт: `index.html`. Сборки нет, всё работает в браузере.
Шрифт Onest подгружается из Google Fonts.

Параметры по умолчанию (из памятки, требуют актуализации): ГСС фиксированного дохода 160%, Юнит Линк 16% годовых, НДФЛ 15%, лимит дохода 30 млн ₽. Их можно менять в блоке «Ставки и лимиты» на странице, а значения по умолчанию лежат в `index.html` (поля `s-gss`, `s-ul`, `s-tax`, `s-lim`).

Публикация: Settings → Pages → Deploy from a branch → main / (root).
«Обновлено».
